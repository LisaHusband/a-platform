# 安全策略 · Security Policy

## 支持的版本 · Supported Versions

项目处于活跃开发期，安全修复仅针对 `main` 分支的最新代码。
The project is under active development; security fixes target only the latest code on `main`.

## 报告漏洞 · Reporting a Vulnerability

**请勿公开提交 Issue 披露安全漏洞。**
**Please do not disclose security vulnerabilities via public issues.**

如发现安全问题，请发送邮件至 **security@a-platform.tech**，并尽量包含：
If you find a security issue, email **security@a-platform.tech** and include where possible:

- 漏洞类型与影响范围 / Vulnerability type and impact
- 复现步骤或概念验证（PoC） / Reproduction steps or a proof of concept
- 受影响的组件 / 接口（如 `/api/v1/...`） / Affected component or endpoint (e.g. `/api/v1/...`)

我们将在 **3 个工作日内** 确认收到，并在评估后协调修复与披露时间。在修复发布前请勿公开细节。
We will acknowledge receipt within **3 business days** and coordinate a fix and disclosure timeline. Please do not disclose details publicly until a fix is released.

感谢你以负责任的方式协助保护用户。
Thank you for helping protect our users responsibly.
